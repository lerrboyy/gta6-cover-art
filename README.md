Vice Panels turns a photo and a caption into multi-panel GTA-style cover art: a hero panel on top, two panels below, a bold caption band, sunset or neon colour grades, and PNG export in square 1080 x 1080, portrait 1080 x 1350 and landscape 1920 x 1080. Load one photo for all panels or a different photo per panel, zoom each panel, and edit the caption live.

## Run it

```sh
node serve.ts
```
